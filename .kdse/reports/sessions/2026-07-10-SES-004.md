#### 2. Key Features

##### Fragment Structure
- Transport header: 1 byte (FIR + FIN + Seq)
- FIR bit (0x80): First fragment indicator
- FIN bit (0x40): Final fragment indicator
- Sequence number: 6 bits (0-63, modulo 64)

##### Fragmenter
- Segments Application PDUs into transport fragments
- Handles single and multi-fragment messages
- Sequence number management (wraps at 63)
- EncodedFragments() for direct byte output

##### Reassembler
- Reassembles fragments into complete messages
- Sequence number validation
- State machine: WaitingFirst → Reassembling → Complete
- Reset capability for new messages

##### Constants
| Constant | Value | Description |
|----------|-------|-------------|
| `MaxFragmentData` | 291 bytes | Max data per fragment |
| `SeqMax` | 63 | Maximum sequence number |
| `SeqMod` | 64 | Sequence number modulus |
