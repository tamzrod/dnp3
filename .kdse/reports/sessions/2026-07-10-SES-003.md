## Implementation Completed

### Data Link Layer (`internal/dll/`)

Created three sub-packages implementing IEEE 1815-2012 Section 5:

#### 1. CRC Package (`crc/`)

**File:** `crc/crc16.go`

Implements CRC-16-DNP calculation:
- Polynomial: `x^16 + x^13 + x^12 + x^11 + x^10 + x^8 + x^6 + x^5 + x^2 + 1`
- LSB-first (reflected) calculation per spec
- Two functions: `CRC16()` and `CRC16Quick()` for validation

#### 2. Frame Package (`frame/`)

**Files:**
- `frame/frame.go` - Main implementation
- `frame/frame_test.go` - Unit tests

Implements frame encoding/decoding:
- Frame structure per IEEE 1815-2012 Section 5.2
- Control byte parsing (DIR, PRM, FCB, FCV, DFC, FuncCode)
- Address handling (0x0000-0xFFFF, including broadcast)
- CRC validation

#### 3. Link Package (`link/`)

**Files:**
- `link/link.go` - State machine implementation
- `link/link_test.go` - Unit tests

Implements the link state machine:
- States: LinkDown, LinkReset, Operational, WaitingConfirm, WaitingResponse, Error
- Roles: Primary, Secondary
- Modes: Unbalanced (Master-Outstation), Balanced
- Frame handling for both primary and secondary endpoints
