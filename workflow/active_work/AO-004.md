This is subset interoperability evidence, **not** general IEEE 1815 certification or production readiness.

## Interoperability matrix (execute only after an accepted isolation/readiness gate)

- Test Go Master → OpenDNP3 Outstation independently, plus OpenDNP3 Master → Go Outstation where the pinned reference harness can issue the same controls; if either direction cannot be executed, mark NOT_RUN with limitation, not PASS.
- For each G41V1–V4: frozen independent value and boundary vectors, qualifier `0x28` count 1, index encoding, little-endian exact object/status response, matching returned value, successes and explicit non-success statuses.
- V3/V4: preserve exact signed-zero bits and positive/negative subnormals, reject NaN and ±Inf at the Go boundaries before handler side effects, reject changed echo bit patterns; exercise finite extremes and negative values. If peer's non-finite policy differs, report divergence instead of weakening our owner-approved policy.
- Invalid/truncated/wrong variation/index/value/count/qualifier/extra-object response and negative master/outstation cases must not report false SUCCESS; verify error-IIN mapping and ambiguous UNKNOWN/quarantine behavior. Check timeout/cancellation/concurrent control and **single-shot/no blind retry**.
- Record raw original PCAP(s), capture provenance, hashes, packet-to-.vec derivation procedure, literal on-wire hexadecimal frames, CRC checks, detailed PASS/FAIL/NOT_RUN and reproducibility. Do not label internal master↔outstation loopback as independent peer evidence.
- Negative tests must not trigger application-side actual controls; use an in-memory handler only. No SBO, DirectOperateNoResponse, new qualifiers `0x17`, batch commands, G42–G44, point/unit scaling, physical I/O, production/SCADA/NGCP traffic, or broad conformance claims.
