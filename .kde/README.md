## Overview

This is the Knowledge Discovery Engine Runtime for the DNP3 Library project. It provides the framework for evidence-based engineering decisions through systematic investigation and analysis.

## Governance Authority

The KDE Runtime operates under the **Governance Authority Hierarchy** (per KDE-INV-002):

```
Tier 1: Governance Authority (External)
    ↓ defines
Tier 2: Runtime Authority (This Runtime)
    ↓ authorizes
Tier 3: Execution Authority (Agents/Humans)
    (with Approval Authority for oversight)
```

See [`.kde/governance/GOVERNANCE-HIERARCHY.md`](governance/GOVERNANCE-HIERARCHY.md) for details.

## Prerequisites

The KDE Runtime requires:
- **Python 3.10+** with PyYAML
- **Go 1.18+** (for Go project verification)

### Non-installing dependency checks (default)

KDE bootstrap gates check the local Python/PyYAML environment without installing or downloading packages. Missing dependencies produce a blocked result; separately approved provisioning must happen outside automatic agent startup. Go installation and module download are never implicit.

```bash
python3 --version
python3 -c 'import yaml; print(yaml.__version__)'
python3 .kde/bootstrap/gates.py --quick
```

## Quick Start

### Using Make (non-installing checks; explicit KDE start only)

```bash
# Non-installing quick preflight
make kde-quick

# Non-installing full check
make kde-check

# Start KDE runtime with quick preflight
make kde-start
```

### Direct Commands (Recommended for AI/Sandbox)

```bash
# 1. Observation-only preflight (skip slow checks)
python3 .kde/bootstrap/gates.py --quick

# 2. Start runtime
python3 -c "import sys; sys.path.insert(0, '.kde'); from runtime.runtime import demo; demo()"

# 3. Run preflight health check
python3 .kde/runtime/preflight.py

# 4. Check runtime state
cat .kde/runtime/state.json
```
