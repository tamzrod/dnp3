# KDE Experts

Domain expert knowledge bases for the Knowledge Discovery Engine.

## Expert Categories

- **DNP3 Protocol Expert**: IEEE 1815 protocol implementation knowledge
- **KDE Governance Expert**: KDE Runtime governance and policies

## Expert Specification

Each expert contains:
- Domain knowledge
- Rules and constraints
- Best practices
- Reference standards

## Expert Usage

Experts are referenced during investigations to provide domain-specific knowledge:

```python
# Example usage
from kde.experts import ExpertRegistry

registry = ExpertRegistry()
dnp3_expert = registry.get("DNP3-EXPERT-001")
print(dnp3_expert.get_rules())
```
