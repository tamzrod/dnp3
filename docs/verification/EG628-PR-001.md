## Selected patches (generic supported-path only)

1. Static Class-0 READ (`internal/outstation/outstation.go`)
   - `staticValueSize` layout table; packed G1V1/G10V1 block sizing.
   - Qualifier/count selection: `0x07` at <=255, `0x27` at 256..65535 via
     `appendCountQualifier` / `appendIndexedCountQualifier`, no count wrapping;
     `staticDropped` -> explicit IIN `OBJECT_UNKNOWN` when no block is
     representable.
   - `requestObjectHeaderSize` now returns `(size, ok)`; unknown qualifiers are
     rejected instead of being guessed.
   - `validateReadHeaders` validates the whole request before staging any
     output; `event_report.go` `classMask` follows the new signature.
   - Request-scoped IIN bits (`FuncUnknown`, `ObjectUnknown`, `ParameterError`,
     `AlreadyExecuting`, `BadConfig`) are cleared per exchange so a rejected
     request cannot pollute later responses; station IIN is preserved.
2. G12V1 CROB (`internal/outstation/outstation.go`, `pkg/dnp3/outstation/server.go`)
   - Qualifier `0x17` (index8/count8) header parsing, byte-accurate G12V1 echo
     that preserves the request header, control fields and a truthful status
     octet (`buildG12V1EchoObject`, `isSingleG12V1Control`, `objectQualifier`).
   - `executeControl` receives the request qualifier.
   - SBO safe default: `defaultSBOTimeoutMS = 10000` when a caller supplies a
     zero/negative internal `SBOTimeout`; public `Config.SBOTimeout` and
     `WithSBOTimeout` propagate it to the internal outstation.
   - Bridge status carrier: unsupported operation codes and malformed pulse
     (count 0) are refused with `ControlBadFormat`; a handler's non-success
     status is carried as a definite wire status instead of a status-less error
     response; NUL (`0x00`) is a true no-op that never reaches a handler; latch
     commands normalise the legacy `OnTime`/`OffTime` fields (wire values are
     unchanged on the object itself).
3. Generic READ path (`pkg/dnp3/master/client.go`)
   - G10 (Binary Output Status) added to the read allow-list and to
     `ReadResponse.BinaryOutputs`; packed G10V1 decode; `skipGroupData` packed
     handling for G10 so a following header is not misread.
   - `IntegrityPoll` primary request and per-group fallback include G10.
   - G1V2/G2V2 without-flags decode corrected to bit 7 state + low-bit quality.
