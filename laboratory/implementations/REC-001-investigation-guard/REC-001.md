## Implementation

### File Created

`.kde/runtime/investigation_guard.py`

### Components

| Component | Description |
|-----------|-------------|
| `InvestigationArtifactGuard` | Main guard class |
| `check_tool_use()` | Pre-tool execution check |
| `BLOCKED_TOOLS` | Tools requiring investigation context |
| `EXEMPT_TOOLS` | Tools always allowed |
| `_detect_investigation_context()` | Extracts INV-XXX/LAB-XXX from path |
| `format_violation_message()` | Human-readable violation message |

### Pattern Followed

Consistent with existing `FileBoundaryGuard`:
- Same dataclass pattern
- Same violation result structure
- Same statistics tracking
- Human-readable violation messages

## Usage

```python
from .investigation_guard import create_guard

guard = create_guard()
result = guard.check_tool_use(
    tool_name="terminal",
    args={"command": "go run test.go"},
    working_dir="/workspace/project/dnp3/laboratory/investigations/INV-066"
)

if not result.allowed:
    print(guard.format_violation_message(result))
    # BLOCK execution
```
