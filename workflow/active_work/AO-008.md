## Proposed supported contract (NOT YET APPROVED OR IMPLEMENTED)

**Explicit opt-in on BOTH roles, default Reject:** G41V1 signed int32, V2 signed int16, V3 IEEE float32, V4 IEEE float64; TCP; one indexed point (count 1, evidenced qualifier `0x28`), **Direct Operate WITH response** only. Client and outstation must each opt in independently; master-only or outstation-only opt-in cannot accidentally execute a control. The existing G12V1/CROB and Class-0 v0 path stays unchanged.

**Stable API decision for KDE approval:** Candidate `master.WithAnalogControl()` / `outstation.WithAnalogControl()` (names and exact signatures are **proposals**, not existent APIs). Prefer keeping the existing `WithExperimentalAnalogControl()` as an explicit backward-compatible alias for current lab consumers; both paths must be tested and documented, and no default auto-enablement permitted. KDE may approve a different exact stable option name with recorded compatibility justification. **Do not implement a name or change current admission behavior before architecture authorization.**

**Typed-only controls:** `types.NewAnalogInt32Control`, `NewAnalogInt16Control`, `NewAnalogFloat32Control`, `NewAnalogFloat64Control`; preserve strict value-group/variation matching. The legacy ambiguous `types.NewAnalogControl(float64)` **must remain Reject, even under approved opt-in**. No implicit float64-to-V1 coercion or silent narrowing.

**Response/failure safety:** Full command echo (group, variation, qualifier/count, indexed point, typed exact-bit value), per-point status and no false SUCCESS; malformed objects/CRC/index/count/qualifier, NaN/Inf, unsupported variation/mode, nil handler, mismatch, timeout, after-send disconnect/unknown, concurrent controls and blind retry must fail closed with the existing quarantine policy. Rejected requests must not mutate handler state or send a G41 control from default master.

**Known exclusions:** OpenDNP3 3.1.2 normalizes V3/V4 `-0.0` and smallest subnormal to `+0.0`; this is documented **FAIL/DIVERGENCE** and the Go master must fail closed, **not** accept normalized echo as valid. Only a single independently tested stack/version. Reverse-direction negative fault injection remains **NOT_RUN**. No SBO, Direct Operate No Response, G41 WRITE, multi-point or batch G41, legacy constructor, field/NGCP utility point index/scale/unit mapping, generalized IEEE 1815 certification or production claims.

**Profile/version migration decision:** Prefer a **new versioned scoped opt-in profile amendment** while retaining v0 Reject in historical v0 (subject to KDE approval); a mere update to docs without a working stable API is unacceptable. Specify exact version, backwards compatibility, release/API messaging and rollback in the design decision. Never imply that publishing a profile alone activates opt-in or that experimental support is officially released.
