**Known caveats / exclusions for a specific support claim:**

1. **Signed-zero / subnormal float normalization (FAIL/DIVERGENCE).** OpenDNP3
   3.1.2 normalizes `-0.0` and subnormals to `+0.0` on the command echo; the Go
   master fails closed by design. A promotion should either (a) document this as
   an explicit peer-interop exclusion with a defined fail-closed outcome, or
   (b) additionally define a normalization policy — but **never** weaken
   validation.
2. **Single independent peer/version only.** All external evidence is against
   OpenDNP3 3.1.2. Any promotion claim must stay scoped to that peer/version
   until a second independent stack/version is captured.
3. **Excluded variants (must remain excluded):** SBO, Direct-Operate-No-Response,
   G41-via-WRITE, multi-point/batched G41, the legacy `NewAnalogControl(float64)`
   constructor, and field/NGCP/SCADA point/scale/units mapping.
4. **Not independently captured:** reverse-direction fault injection (Go
   outstation behind the proxy vs C++ master) remains `NOT_RUN`.

**Recommendation (not a promotion):** G41V1–V4 Direct-Operate-with-response is
**promotion-ready as a scoped candidate** against the OpenDNP3 3.1.2 peer, with
the signed-zero/subnormal normalization recorded as an explicit documented
