## Purpose

This policy establishes requirements for documenting and managing Python dependencies required by the KDE Runtime. It ensures that all dependencies are properly documented to prevent runtime load failures.

---

## Policy Statement

### Rule 1: Dependency Documentation

All Python dependencies required by the KDE Runtime **MUST** be documented in `.kde/bootstrap/requirements.json`.

### Rule 2: Required Fields

Each dependency **MUST** include the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| module_name | Yes | Name of the Python module (pip install name) |
| minimum_version | Yes | Minimum required version |
| import_statement | Yes | How the module is imported in code |
| description | Yes | Purpose of the dependency |

### Rule 3: Dependency Installation

1. Runtime initialization **MUST** check for all documented dependencies
2. If a dependency is missing, the runtime **MUST** either:
   - Install it automatically (if safe), or
   - Report a clear error message listing missing dependencies
3. Installation **SHOULD** be automated in the bootstrap process

### Rule 4: Standard Library

Modules from the Python Standard Library **MUST** be listed in `standard_library` to document which modules are expected to be available without external installation.

## Current Dependencies

Per the requirements.json, the following dependencies are required:

| Module | Version | Purpose |
|--------|---------|---------|
| yaml (PyYAML) | >= 5.0 | YAML parsing for configuration files |

### Standard Library Modules

The KDE Runtime uses the following Standard Library modules (no installation required):

- json, os, sys, time, datetime, pathlib, typing, dataclasses, enum

## Compliance Verification

### Check: Dependency Documentation

Before the KDE Runtime can be considered loadable, verify:

- [ ] `python_dependencies.required` exists in requirements.json
- [ ] All external dependencies are listed with required fields
- [ ] Standard library modules are documented
- [ ] `python_dependencies_installed` is in system_checks

### Check: Runtime Load

The runtime **MUST** successfully load with the following command:

```bash
cd /path/to/repo
python3 -c "
import sys
sys.path.insert(0, '.kde')
from kde.runtime import KnowledgeOnDemandRuntime
runtime = KnowledgeOnDemandRuntime('VERIFICATION')
print('Runtime loaded successfully')
"
```

---

## Violations

| Violation | Severity | Remediation |
|-----------|----------|-------------|
| Missing dependency documentation | HIGH | Add to requirements.json |
| Missing dependency causes load failure | CRITICAL | Document and install dependency |
| Standard library not documented | MEDIUM | Add to standard_library list |

---

## Enforcement

1. **Bootstrap Verification**: Runtime bootstrap checks dependencies
2. **Pre-Load Verification**: Any code loading KDE Runtime must verify dependencies
3. **Documentation Requirements**: PRs adding dependencies must update requirements.json
