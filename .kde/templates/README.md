# KDE Templates

Templates provide standardized formats for KDE artifacts.

## Template Types

| Template | File | Purpose |
|----------|------|---------|
| Investigation | INV.md | Investigation document templates |
| Experiment | EXP.md | Experiment document templates |
| Implementation | IMP.md | Implementation specification |
| Decision | TDR.md | Technology Decision Records |

## Template Files

| File | Description |
|------|-------------|
| INV.md | Investigation template (README, SPEC, CONCLUSION) |
| EXP.md | Experiment template |
| IMP.md | Implementation specification template |
| TDR.md | Technology Decision Record template |

## Usage

### Create Investigation

```bash
mkdir -p laboratory/investigations/KDE-INV-XXX
cp .kde/templates/INV.md laboratory/investigations/KDE-INV-XXX/README.md
```

### Create Experiment

```bash
mkdir -p laboratory/experiments/PROJECT-EXP-XXX
cp .kde/templates/EXP.md laboratory/experiments/PROJECT-EXP-XXX/README.md
```

### Create Decision

```bash
cp .kde/templates/TDR.md laboratory/decisions/TDR-XXX.md
```
