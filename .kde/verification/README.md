# KDE Verification

Verification system for validating KDE outputs and processes.

## Verification Types

- **Process Verification**: Verify investigation processes
- **Output Verification**: Verify decision outputs
- **Compliance Verification**: Verify governance compliance
- **Quality Verification**: Verify artifact quality

## Verification Checks

### Compliance Verification

| Check | Description | Severity |
|-------|-------------|----------|
| Policy Documents | Required policies exist | ERROR |
| Bootstrap Gates | gates.py and dependencies documented | ERROR |
| Artifact Naming | Follows naming conventions | WARNING |
| Structure | Required files present | ERROR |

### Quality Verification

| Check | Description | Severity |
|-------|-------------|----------|
| Frontmatter | Required fields present | WARNING |
| Evidence Section | Evidence/research section exists | WARNING |

## Running Verification

### CLI Usage

```bash
# Run all verification checks
python3 .kde/verification/compliance.py

# Output as JSON
python3 .kde/verification/compliance.py --json
```

### Python Usage

```python
from kde.verification.compliance import verify_all, print_verification_result

result = verify_all()
print_verification_result(result)

if result.passed:
    print("All checks passed!")
else:
    print(f"Errors: {len(result.errors)}")
    print(f"Warnings: {len(result.warnings)}")
```

## Verification Result Codes

| Exit Code | Meaning |
|-----------|---------|
| 0 | All checks passed |
| 1 | One or more checks failed |
