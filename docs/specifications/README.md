# Specifications

This directory contains DNP3 protocol specifications and related documents.

## IEEE 1815

The primary specification for go-dnp3 is **IEEE 1815-2012** - Standard 
for Communication Performance and Timing Profiles Between Substation 
Computers and RTUs Using DNP3.

## Document Organization

```
specifications/
├── ieee-1815/        # IEEE 1815 documentation (when available)
├── references/       # Reference documents
└── notes/           # Specification notes
```

## Usage

All implementation is based on these specifications. Before implementing 
any feature, consult the relevant specification documents.
