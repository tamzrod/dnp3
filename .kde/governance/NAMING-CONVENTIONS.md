## Purpose

This policy establishes mandatory naming conventions for all laboratory artifacts to ensure consistency, traceability, and prevent naming conflicts.

---

## Artifact Naming Rules

### Rule 1: Prefix Requirements

| Artifact Type | Directory | Prefix | Example |
|--------------|-----------|--------|---------|
| Investigation (KDE) | `investigations/` | `KDE-INV-` | `KDE-INV-001/` |
| Investigation (Project) | `investigations/` | `PROJECT-INV-` | `PROJECT-INV-001/` |
| Experiment | `experiments/` | `PROJECT-EXP-` | `PROJECT-EXP-001/` |
| Decision | `decisions/` | `TDR-` | `TDR-001.md` |
| Implementation | `implementations/` | `PROJECT-IMP-` | `PROJECT-IMP-001/` |
| Review | `reviews/` | `PROJECT-REV-` | `PROJECT-REV-001.md` |

### Rule 2: Directory Placement

| Prefix | Valid Directory |
|--------|-----------------|
| `KDE-INV-*` | `investigations/` |
| `PROJECT-INV-*` | `investigations/` |
| `PROJECT-EXP-*` | `experiments/` |
| `TDR-*` | `decisions/` |
| `PROJECT-IMP-*` | `implementations/` |
| `PROJECT-REV-*` | `reviews/` |

### Rule 3: ID Sequence

- **Investigations (KDE)**: Sequential `KDE-INV-001`, `KDE-INV-002`, etc.
- **Investigations (Project)**: Sequential `PROJECT-INV-001`, `PROJECT-INV-002`, etc.
- **Experiments**: Sequential `PROJECT-EXP-001`, `PROJECT-EXP-002`, etc.
- **Decisions**: Sequential `TDR-001`, `TDR-002`, etc.
- **Implementations**: Sequential `PROJECT-IMP-001`, `PROJECT-IMP-002`, etc.
- **Reviews**: Sequential `PROJECT-REV-001`, `PROJECT-REV-002`, etc.

---

## Enforcement

### Pre-Creation Check

Before creating any laboratory artifact:
1. Verify the correct prefix for the artifact type
2. Verify the correct directory for the artifact type
3. Check for ID sequence continuity

### Violation Detection

| Violation Type | Example | Required Action |
|----------------|---------|-----------------|
| Wrong prefix | `investigations/DNP3-EXP-004/` | Rename to `DNP3-INV-XXX` |
| Wrong directory | `experiments/DNP3-INV-012/` | Relocate to `investigations/` |
| Duplicate ID | Two `DNP3-EXP-003/` | Reassign one ID |

---

## Rationale

1. **Traceability**: Unique, predictable IDs enable quick artifact location
2. **Consistency**: Standardized naming prevents confusion
3. **Automation**: Enables tooling for artifact management
4. **Scientific Validity**: Clear identification supports evidence chains
