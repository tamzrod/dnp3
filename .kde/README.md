## Overview

This is the Knowledge Discovery Engine Runtime for the DNP3 Library project. It provides the framework for evidence-based engineering decisions through systematic investigation and analysis.

## Governance Authority

The KDE Runtime operates under the **Governance Authority Hierarchy** (per KDE-INV-002):

```
Tier 1: Governance Authority (External)
    ↓ defines
Tier 2: Runtime Authority (This Runtime)
    ↓ authorizes
Tier 3: Execution Authority (Agents/Humans)
    (with Approval Authority for oversight)
```

See [`.kde/governance/GOVERNANCE-HIERARCHY.md`](governance/GOVERNANCE-HIERARCHY.md) for details.

## Prerequisites

The KDE Runtime requires:
- **Python 3.10+** with PyYAML
- **Go 1.18+** (for Go project verification)

### Automatic Installation (Recommended)

The bootstrap gates will automatically attempt to install missing dependencies:

```bash
# Run preflight check - auto-installs PyYAML if missing
python3 .kde/bootstrap/gates.py --quick
```

### Manual Installation

For sandboxed environments (OpenHands, etc.), install to user-local directory:

```bash
# Install Python dependencies
pip install --user -r .kde/requirements.txt

# Install Go toolchain (if needed)
curl -sL https://go.dev/dl/go1.22.5.linux-amd64.tar.gz | tar -xz -C $HOME/go --strip-components=1
echo 'export PATH=$HOME/go/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

## Quick Start

### Using Make (Recommended)

```bash
# Quick preflight check (~0.1s)
make kde-quick

# Full preflight check (~2.2s)
make kde-check

# Start KDE runtime with quick preflight
make kde-start
```

### Direct Commands

```bash
# Quick preflight (skip slow checks)
python3 .kde/bootstrap/gates.py --quick

# Full preflight (includes go mod verify)
python3 .kde/bootstrap/gates.py --full

# Start runtime
python3 -c "import sys; sys.path.insert(0, '.kde'); from runtime.runtime import demo; demo()"
```
