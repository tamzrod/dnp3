## Implementation contract
- Master: only `Group=41, Variation=1, CommandType=DirectOperate` accepted for the new analog path. For G41V1, emit group `0x29`, variation `0x01`, qualifier `0x28` (16-bit count + 16-bit index), count `01 00`, index low byte first, signed int32 low byte first, trailing request status `00`. Never truncate/round/fold out-of-range values. Reject malformed/unsupported combinations **before sending**. Keep G12V1 admitted as before.
- Outstation: parse G41V1 with strictly bounded lengths and correct qualifier/index handling (`0x28` and, if implemented and verified, `0x17`); reject unsupported qualifiers/variations or malformed prefixes/counts **without calling host handler**. Do not let any fallback decode unsupported variations.
- Public handler bridge: preserve actual Direct Operate command semantics (do not falsely present `SelectThenOperate`); use a generic, app-owned analog command callback, never hard-code plant-specific point names, units, limits or permissions. A valid handler refusal must not be converted to SUCCESS.
- Response: return object echo with index, int32 value and one command-status octet; master must match the expected group/variation/index and treat absent, truncated, malformed, mismatched or non-SUCCESS statuses as failure/UNKNOWN, not success. Respect existing control single-shot gate/quarantine/timeout and **no blind retry** constraints.
- Keep G41 marked **UNSUPPORTED** in `active_work/supported-profile.md` until AO-004 independent peer verification and AO-005 approved supported-profile changes. Do not claim external interoperability or utility compliance based on local tests.
