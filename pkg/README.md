# Public Packages

This directory contains public Go packages that can be imported by users.

## Structure

```
pkg/
└── dnp3/          # Main DNP3 package
    ├── master/    # Master station API
    ├── outstation/ # Outstation API
    └── types/     # Common types
```

## Usage

```go
import "github.com/your-org/go-dnp3/pkg/dnp3"
```
