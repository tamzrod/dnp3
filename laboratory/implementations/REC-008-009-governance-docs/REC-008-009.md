## REC-009: Live Status Surface

### Generator: `status_surface.py`

Shows:
- Current Engine and Seed
- Active Investigations (top 10)
- Recent Experiments (top 10)
- Open Questions
- Pending Promotions
- Recent Lessons

### Usage

```bash
# Generate status
python3 .kde/runtime/status_surface.py

# Or in Python
from .status_surface import StatusSurfaceGenerator

generator = StatusSurfaceGenerator()
surface = generator.generate()
print(generator.format_markdown(surface))
```

### Output Format

```markdown

**Generated**: 2026-07-29 10:30:00

## Current Configuration

| Component | Value |

## Active Investigations

...
```
