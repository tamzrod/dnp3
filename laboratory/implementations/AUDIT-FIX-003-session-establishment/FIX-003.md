# FIX-003: Proper DNP3 Session Establishment

**Issue**: `Connect()` only sets TCP state, not DNP3 session  
**Fix**: Perform link-layer handshake in Connect()  
**Severity**: HIGH

## Problem

Old `Connect()` only set state after TCP dial:

```go
// Old: TCP-only connection
func (m *Master) Connect() error {
    m.SetState(StateConnecting)
    m.SetState(StateConnected)  // Just after TCP dial!
    return nil
}
```

No DNP3 link-layer exchange occurred. "Connected" meant TCP only.

## Solution

`Connect()` now performs proper DNP3 session establishment:

```go
// New: DNP3 session establishment
func (m *Master) Connect() error {
    m.SetState(StateConnecting)
    
    // Perform DNP3 link-layer handshake
    if err := m.performLinkHandshake(); err != nil {
        m.SetState(StateError)
        return err
    }
    
    m.SetState(StateConnected)
    m.SetState(StateActive)  // True session established
    return nil
}
```

### Handshake Sequence

```
1. TCP connect (handled by transport)
2. Send Reset Link Stations (DLL Function Code 0)
3. Wait for acknowledgment
4. Set StateActive (session ready)
```

## New Functions

| Function | Purpose |
|----------|---------|
| `performLinkHandshake()` | Orchestrates link-layer handshake |
| `sendResetLink()` | Builds and sends Reset Link Stations frame |

## State Machine

```
Disconnected → Connecting → Connected → Active
                              ↓
                            Error (on failure)
```
