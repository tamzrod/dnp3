### File Created

### Components

| Component | Description |
|-----------|-------------|
| `PreToolCheck` | Main hook class |
| `verify_tool()` | Verify tool permission |
| `verify_or_raise()` | Verify or raise exception |
| `check_tool()` | Convenience function |
| `require_investigation()` | Require context or raise |
| `InvestigationViolation` | Exception class |

### Dependencies

- REC-001: InvestigationArtifactGuard

## Usage

### Basic Usage
```python
from .pre_tool_check import check_tool, require_investigation

# Check if allowed
result = check_tool("terminal", {"command": "go run test.go"})
if not result.allowed:
    print(result.violation_message)

# Or require and get context
ctx = require_investigation("file_editor", {"path": "/laboratory/.../test.go"})
# Safe to execute, ctx contains investigation context
```

### Integration with Tool Execution

```python
def execute_tool(tool_name, args):
    checker = get_pre_tool_check()
    try:
        ctx = checker.verify_or_raise(tool_name, args)
        # Execute tool
        return execute(tool_name, args)
    except InvestigationViolation as e:
        print(e)
        return None
```

## Integration with Runtime

To fully integrate, add to tool execution layer:

```python
# In tool execution wrapper
def execute_tool(tool_name, args):
    result = check_tool(tool_name, args)
    if not result.allowed:
        raise InvestigationViolation(result.violation_message)
    return actual_tool_execution(tool_name, args)
```
