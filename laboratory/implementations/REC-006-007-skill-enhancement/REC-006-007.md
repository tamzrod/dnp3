### Components

| Component | Description |
|-----------|-------------|
| `SkillEnforcementParser` | Parses enforcement sections from skills |
| `SkillEnforcementRegistry` | Tracks active enforcement rules |
| `EnforcementRule` | Rule structure |
| `register_skill_enforcement()` | Convenience function |

## Skill Format

Skills can now include enforcement sections:

```markdown
# Skill: Investigation Framework

## Description
Guides investigation workflow...

<!-- ENFORCEMENT -->
- rule: investigation_required
  block_on_fail: true
  tools_blocked: [terminal, file_editor]
  message: "Create investigation artifact first"
- rule: run_doc_required
  block_on_fail: true
  tools_blocked: [terminal]
  message: "Document experiment runs first"
-->
```

## Usage

```python
from .skill_enforcement import register_skill_enforcement, get_skill_registry

# When skill is invoked
enforcement = register_skill_enforcement("kde-investigation-framework")
if enforcement.enabled:
    print(f"Registered {len(enforcement.rules)} rules")

# Check blocked tools
registry = get_skill_registry()
if registry.is_tool_blocked("terminal"):
    print("Terminal is blocked by active skill rules")
```

## Supported Rules

| Rule | Blocks | Purpose |
|------|--------|---------|
| investigation_required | terminal, file_editor | Require investigation artifact |
| experiment_required | terminal, file_editor | Require experiment artifact |
| run_doc_required | terminal | Require run documentation |
| synthesis_before_new | terminal | Require synthesis first |
| evidence_required | terminal | Require evidence files |
