#### 2. Key Features

##### Application Control Field (1 byte)
- FIR bit (0x80): First fragment indicator
- FIN bit (0x40): Final fragment indicator
- CON bit (0x20): Confirmation required
- UNS bit (0x10): Unsolicited response
- Sequence number: 4 bits (0-15)

##### APDU Structure
- Application Control (1 byte)
- Function Code (1 byte)
- Objects (variable)

##### Internal Indication (IIN) Field (2 bytes)
- IIN.1: Device status flags (AllStop, ByteOver, Busy, etc.)
- IIN.2: Extended status flags (ConfigError, TimeSync, etc.)

##### Function Codes
- Master→Outstation: READ, WRITE, SELECT, OPERATE, etc.
- Outstation→Master: RESPONSE, UNSOLICITED_RESPONSE, NO_ACK
