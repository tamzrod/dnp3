# Laboratory Decisions

This directory contains technology decision records (TDRs) for the project.

## Purpose

Technology Decision Records document the rationale behind significant technology choices, ensuring future contributors understand why certain decisions were made.

## Naming Convention

TDRs follow the pattern: `TDR-XXX.md`

## When to Create a TDR

Create a TDR when:
- Evaluating technology alternatives
- Making significant architectural decisions
- Selecting libraries or frameworks
- Establishing coding standards
