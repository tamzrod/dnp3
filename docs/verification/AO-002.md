## 2. G41V1 wire contract (implemented)

Verified independent OpenDNP3 3.1.2 Group 41 object (AO-001 §3): a signed **int32** value
serialized **little-endian** followed by **one command-status octet**. G41V1 is `0x29 0x01`.

Direct Operate request object (qualifier `0x28` = 16-bit count + 16-bit index):

```
29 01 28 01 00   group 41, variation 1, qualifier 0x28, count 0x0001
<index LE>       first point index (2 octets, low byte first)
<value LE>       signed int32, low byte first
00               request object command status (SUCCESS)
```

Independent frozen literals (AO-001 §6 / AO-002 acceptance #1), object header + record only
(no APDU function/IIN bytes):

| index | value | object bytes |
|-------|-------|--------------|
| 0 | `2300` | `29 01 28 01 00 00 00 FC 08 00 00 00` |
| 0 | `-1` | `29 01 28 01 00 00 00 FF FF FF FF 00` |

Both the master encoder and the outstation decoder are verified against these literals
independently — not against each other's output.

## 3. Implementation summary

- **Master encoder** (`internal/master/master.go`, `buildControlRequest`): the G41 branch now emits
  group `0x29`, variation `0x01`, qualifier `0x28`, count `01 00`, index low byte first, signed
  int32 low byte first, trailing `00`. Any other G41 variation, a non-`int32`/`int`/`int64` value,
  a float (even integral), or an out-of-range integer returns a `nil` request — a **definite
  pre-send rejection**, never a truncation, rounding or wrap. The prior non-conformant 16-bit
  path for G41 was removed; G42–G44 are no longer encoded (the `default` case rejects).
- **Master status parser** (`internal/master/master.go`): `parseCommandStatus`,
  `commandStatusForQualifier`, `skipObject`, `objectLayout` and `containsG12V1Header` are now
  group-aware via `isControlObject`/`controlPointValueSize` (G12V1 = 11-octet point; G41V1 =
  5-octet point: int32 + status). `resolveOperateStatus` takes the request APDU; for a G41V1
  request it requires the echoed object to match group/variation/**index** exactly
  (`g41v1CommandStatus`/`parseG41V1Record`) and never falls back to IIN success. G12V1 behavior is
  unchanged (including the IIN-only success path for G12V1).
- **Outstation parser** (`internal/outstation/outstation.go`): `executeControl` G41 branch and the
  `handleWrite` G41 branch accept **only** variation 1 with an exact 5-octet record
  (int32 LE + status); any other variation or wrong length is rejected with `ErrInvalidRequest`
  **without calling the host handler**. `handleDirectOperate` echoes the G41V1 object (index,
  int32 value, SUCCESS status) on success; a handler error yields an error response (never a
  SUCCESS echo).
- **Public bridge** (`pkg/dnp3/outstation/server.go`): a G41V1 write is carried as a typed
  `*types.AnalogInt32CommandValue` with `CommandType: DirectOperate` (previously hard-coded
  `SelectThenOperate`, now corrected). A non-`int32`/`int16` value is rejected before the handler.
- **Public gate** (`pkg/dnp3/master/client.go`): a fail-closed object gate admits only G12V1 and
  G41V1; any other group/variation is rejected with `ErrUnsupportedOption` **before any wire
  traffic**. G12V1 admission and the DirectOperate/SelectThenOperate/NoResponse command-type gate
  are preserved.
- **Types** (`pkg/dnp3/types/commands.go`): added `AnalogInt32CommandValue` (int32) and
  `NewAnalogInt32Control`; the legacy `AnalogCommandValue`/`NewAnalogControl` (float64 carrier) is
  retained for API continuity and is not the verified G41V1 path.

## 4. Tests added (byte literals and fail-closed negatives)

- `internal/master/g41v1_control_test.go`:
  - `TestBuildControlRequestG41V1Golden` — encoder vs the independent literals above plus int32
    min/max at index `0x1234`.
  - `TestBuildControlRequestG41V1Rejections` — V2/V3/V4, float32/float64 values, int64 overflow
    and underflow, nil value → `nil` request.
  - `TestOperateG41V1StatusMatrix` — canned G41V1 echo: SUCCESS→success; non-SUCCESS byte surfaced
    as-is; IIN-only (no object)→`ErrControlOutcomeUnknown` (never success).
  - `TestOperateG41V1MismatchedObjectNotSuccess` — wrong echoed index is never success.
  - `TestParseCommandStatusG41V1` — G41V1 status octet read; truncated object → `Unknown`.
- `internal/outstation/g41v1_control_test.go`:
  - `TestOutstationG41V1DecodeGolden` — decode `2300` little-endian to `int32(2300)`, echo object
    with SUCCESS status byte-exact; `TestOutstationG41V1DecodeNegative` — `-1`.
  - `TestOutstationG41RejectionsNoHandlerCall` — V2/V3/V4, truncated value, bad qualifier: error
    with **no handler call**.
  - `TestOutstationG41V1HandlerRefusalNotSuccess` — handler error is an error response, not SUCCESS.
  - `TestOutstationG41V1DoesNotTouchCROB` — no cross-group leakage into `WriteBinaryOutput`.
- `pkg/dnp3/master/g41v1_public_test.go`:
  - `TestPublicOperateGateRejectsUnsupportedObjects` — G41V2/V3/V4, G42V1, G30V1 rejected with
    `ErrUnsupportedOption` and **no transmission**.
  - `TestPublicOperateG41V1Success` / `TestPublicOperateG41V1NonSuccess` — public status surface.
- `pkg/dnp3/outstation/bridge_status_matrix_test.go`:
  - `TestBridgeAnalogOutputG41V1Semantics` — typed int32 + DirectOperate (not SelectThenOperate).
  - `TestBridgeAnalogOutputG41V1RejectsWrongType` — non-integer value rejected before handler.
- `pkg/dnp3/types/types_test.go`:
  - `TestNewAnalogInt32Control` — constructor group/variation/value/type.
